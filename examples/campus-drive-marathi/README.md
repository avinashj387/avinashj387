# Eagle Hi-tech — कॅम्पस ड्राईव्ह (Marathi reel)

A 69.5-second vertical recruitment ad for the Eagle Hi-tech campus drive at
Matoshree College of Engineering & Research Centre, Eklahare, Nashik.

| | |
| --- | --- |
| Output | `eagle-hitech-campus-drive-marathi.mp4` |
| Format | 1080 × 1920 (9:16), 30 fps, H.264 + AAC |
| Length | 69.5 s |
| Language | Marathi throughout |
| Built with | `videogen` (this repo) + Pillow + ffmpeg |

```bash
python3 build.py                                # frames, music, spec, render
python3 voiceover.py --engine edge              # Marathi narration takes
python3 build.py --narration --skip-frames      # re-render with the voice-over
```

## How it is put together

`build.py` is the whole pipeline:

1. **`scenes.py`** composes fourteen 1080 × 1920 PNGs — one per beat of the ad.
2. **`music.py`** synthesises the music bed from scratch (additive synthesis,
   no samples), so nothing in the audio is licensed from anyone.
3. **`videogen`** turns the stills into the film: Ken Burns moves, a different
   transition on almost every cut, and the music mixed underneath.

### Why the text is drawn in Pillow, not by ffmpeg

ffmpeg's `drawtext` has no Indic shaping. Give it `कॅम्पस ड्राईव्ह` and the matras
and conjuncts come out reordered — the exact "gibberish Marathi" failure this
ad could not afford. Pillow with Raqm/HarfBuzz shapes correctly, so every
Marathi glyph is baked into the frames before ffmpeg sees them.

Noto Sans Devanagari carries no Latin letters at all, so a mixed string like
`PF, ESIC इत्यादी कायदेशीर सुविधा` renders its Latin half as `.notdef` boxes in a
single font. `brandkit.py` therefore splits every string into script runs and
draws each run in the font that covers it, on one shared baseline.

## Voice-over

`narration.py` holds the Marathi script, one line per scene, with numbers
spelled out (आठ आणि नऊ सप्टेंबर दोन हजार सव्वीस) so no engine falls back to reading
digits in English. `voiceover.py` speaks it two ways:

- `--engine edge` — **`mr-IN-ManoharNeural`, a natural male Marathi voice.**
  This is the one to ship. It needs to reach Microsoft's speech endpoint.
- `--engine espeak` — a fully offline formant synthesiser. Intelligible
  Marathi, but audibly robotic. A fallback, not a finished ad voice.

Each take is time-fitted to its scene and sped up only if it overruns, never
past 1.35×. If a line still will not fit, `voiceover.py` names it and you can
either shorten the line or lengthen that scene in `build.py`'s `BOARD`.

## Editing it

| Change | Where |
| --- | --- |
| Wording on screen | `scenes.py` |
| Wording in the voice-over | `narration.py` |
| Scene order, length, motion, transitions | `BOARD` in `build.py` |
| Colours, fonts, furniture | `brandkit.py` |
| Icons | `icons.py` |
| Music: key, tempo, arrangement | `music.py` |

`media/` and `*.mp4` are gitignored — everything there is regenerated by
`build.py`, which is the file that is actually under version control.
